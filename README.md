# inventory-management-system-py
Project Description
This is a simple desktop application for managing inventory using a graphical user interface (GUI). It allows users to add, update, delete, and search for products in a database. The application is built with Python and uses Tkinter for the GUI and SQLite for data storage, making it lightweight and easy to set up. Ideal for small businesses or personal use to track product details such as ID, name, category, quantity, and price.

Features
Add Products: Insert new products with unique IDs, names, categories, quantities, and prices.
Update Products: Modify existing product details by ID.
Delete Products: Remove products from the inventory by ID.
Search Products: Search for products by name or category and display matching results.
View All Products: Display a list of all products in a table format.
Data Persistence: All data is stored in a local SQLite database file (inventory.db).
Input Validation: Ensures valid data entry (e.g., integers for ID and quantity, floats for price) with error messages.
User-Friendly GUI: Intuitive interface with input fields, buttons, and a searchable table.
Technologies Used
Python: Core programming language for the application logic.
Tkinter: Standard Python library for creating the graphical user interface.
SQLite: Embedded database for storing and managing product data.
SQLite3: Python module for interacting with the SQLite database.
